# Using the Arandu portal

The portal provides access to simulated Roman alerts currently generated by Arandu.

## Explore alerts

- Use **Calendar** to see daily detection activity.
- Use **Discovery** to search by sky position, classification, or the newest observations.
- Select an object to inspect its light curve, enrichments, and available FITS image cutouts.
- Use **Status** to see whether alert delivery, analysis, the searchable catalogue, and observation images are available.

## Search examples

| Goal | Example |
| --- | --- |
| Search a position | `0.12697 0.4635 10` |
| Find a classification | `classification:candidate_transient` |
| See the newest records | `last:25` |
| Combine both | `last:25 classification:candidate_transient` |

The position-search format is right ascension, declination, and radius in arcseconds.
